# Tarea PokeAPI

Proyecto realizado para consumir la API de Pokémon (PokeAPI).

## Funciones

El proyecto contiene las siguientes funciones:

- `getAllPokemons()`
- `getPokemonById(id)`
- `getPokemonsAbility(abilityName)`
- `getPokemonType(typeName)`
- `getPokemonAbility(id, abilityName)`

## Ejecución

Para probar el proyecto:

```bash
node test.js
